# L4-C implementation design

Authority: user L4-C brief (2026-10-16), plus subsequent explicit general permission to write Skyrim files. Development proceeds autonomously as one milestone. Actual execution still requires a concrete authenticated production candidate and exact immutable plan; none currently exists. Do not ask for another broad approval, invent a production pack/key, use Level B test identity, publish or commit/push.

Extend the SAME SandboxInstaller/MetadataStore/PackageDownloader. Preserve legacy sandbox descriptors/receipts/journals and strict sandbox allowlist. Add internal managed-target capabilities with installation + supported native profile roots and separate protected metadata/cache. Disposable Skyrim-shaped targets are only created under verified OS temp and cannot upgrade to real targets. Recovered real descriptors require trusted Main reattachment; never deserialize write authority.

A prepared plan binds original signed payload/release/publisher, runtime/native/server snapshot evidence, target root identities, ownership receipt, every original file observation, generated activation bytes and exact operations. Main's native confirmation issues a short-lived single-use token for this hash; no renderer destination/key/URL, CLI/env/dev bypass. Missing production pins/release/rights block request/apply. Revalidate before apply and at file/rollback boundaries; refuse active game, links, identity changes, permissions or resources failure.

Engine operations: add/replace/verify, receipt-owned missing repair, controlled remove, and typed @config activation. Reuse staging/verified backups/durable journal/restore. Config changes are journaled but not claimed as ownership over unrelated entries. Removal records intent before unlink and restores verified backup only if target remains absent; foreign replacement causes recovery-required. Repair never overwrites changed managed bytes. No directory cleanup.

Activation supports confidently identified native Steam SSE asterisk plugins.txt subset, preserved formatting/encoding/unrelated entries and explicit dependency order. Reject unsafe encodings, manager ambiguity, ESL/light, uncertain native/server behavior; provide manual plan. loadorder.txt/ccc remain read-only unless adapter proves supported role. Never distribute/manage game runtime, native SKSE/SkyMP or official assets as ordinary mods. Existing V1 direct package format retained; mod BSA requires narrow content policy, existing bounded limits documented.

UI: one management panel on Updates, readonly preflight, real computed plans and conflicts/backups/progress. No enabled production install without production configuration and exact review. Fixture smoke executes same services/engine with independently scoped fixture identity; it never authorizes real target. Retain L1-L4B and fix no unrelated code.

Version0.1.6, same appId/product/exe/storage/NSIS identities. All existing regressions + realistic Windows fixture install/update/repair/remove/activation/termination/recovery/security. NSIS/source+packaged smoke/privacy+protected baseline comparison. Deliver L4C_REPORT.md + exact blocked-candidate L4C_REAL_INSTALL_APPROVAL.md; no L5.
